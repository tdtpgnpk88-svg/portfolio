Connexion

Connecte-toi avec un jeton de ton compte GitHub. Chaque modification que tu publies est enregistrée dans le dépôt et le site se met à jour tout seul.

Créer mon jeton (une seule fois)
  1. Ouvre github.com › Settings › Fine-grained tokens.
  2. Donne-lui un nom (par exemple « Admin portfolio ») et une date d'expiration.
  3. Dans Repository access, choisis Only select repositories puis ton dépôt .
  4. Dans Permissions, règle Contents sur Read and write. Rien d'autre.
  5. Clique sur Generate token, copie le jeton et colle-le ici.

Le jeton reste uniquement dans ce navigateur. Ne le partage avec personne : il permet de modifier ton site.
